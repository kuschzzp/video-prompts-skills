# 可选迭代记录

- 模型版本／平台／生成模式：
- 提示词与输入素材版本：
- 设置（含种子，仅当平台支持）：
- 实际提交的合并正文／局部修订说明／源视频及编辑范围（按模式记录，未取得则未知）：
- 计划时长／实际提交时长设置／输出实测时长（有后处理另记生成原片）：
- 原始预期：
- 实际观察与时间点：
- 证据来源（直接查看／用户描述／尚未取得）：
- 观察方法（连续播放／抽帧间隔／关键事件附近逐帧等）：
- 原因假设与不确定性：
- 本次唯一改动或必要的一组改动：
- 保持不变的内容：
- 重新生成是否获授权、是否实际执行：
- 各目标的结果（动作、终态、姿态、时长、声画等）：改善／无变化／退化／未达标／待验证：
- 经验范围：模型、版本、素材条件及是否已复现：

记录结果，不记录推测性的“必然有效”规则。没有生成时不填成功。
