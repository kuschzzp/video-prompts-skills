# 可选镜头卡

复杂分镜或用户明确需要制作表时使用；不需要的项可省略。不是 API schema，也不要求每次填写全表。

| 项目 | 内容 |
| --- | --- |
| 镜头编号与时间 | 开始、结束、是否有转场 |
| 信息目的 | 观众在这里看见什么变化 |
| 视点与调度 | 跟谁的经验、已知信息、人物走位如何改变关系与构图 |
| 情绪与表演 | 触发 → 可见动作 → 对方响应 |
| 构图与焦点 | 景别、机位、视线、关键交互是否完整可见 |
| 可读性 | 当前画面大小能读到什么；本机位应见背景和应留在画外的对象 |
| 运镜 | 主体相对世界、相机相对主体、画面变化；启动、路径与停止点 |
| 衔接 | 上下镜的视线、动作阶段、方向或连续声音；是否改变时空关系 |
| 光源 | 实际来源、方向、与前镜头关系 |
| 入镜状态 → 出镜状态 | 人物、手、道具、动作阶段 |
| 动作前置条件 | 手是否空闲、谁承重、先放置或交接什么、路线是否可通行 |
| 对白 | 说话人、原文、语言、表达方式与停顿 |
| 其他声音 | 环境延续、动作音触发、音乐来源与变化 |
| 素材职责 | 实际素材编号、继承特征、允许重建部分、身份状态与作用时间 |
| 实现与验证 | 生成意图、实际支持的约束、必要后期及代价 |
