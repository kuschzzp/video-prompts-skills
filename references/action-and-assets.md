# 动作前提与素材使用

复杂持物、多人交互、参考素材重组或同一主体有多个状态时选读。以下方法与模型无关；普通静镜不必逐项展开，也不要求输出内部检查表。

以下例子均为原创虚构教学，不对应用户的真实素材。素材案例仅假设已经查看了所述输入；其中图A、图B是教学代称，不是已上传或已绑定的引用标签。实际任务先查看真实输入，再使用目标平台的实际编号。

## 1. 先给动作腾出可用的手

**判断步骤**

先确认双手分别拿着什么、物体由谁承重，再检查下一个动作需要哪只手。需要腾手时，安排放置、交接或换握，并给物体留下明确支撑。检查动作完成后双手与物体的位置是否仍可接续。

**易误写**

烘焙师双手端着烤盘，用右手拉开柜门，盘子始终水平悬在胸前。

**原创可用写法**

```text
烘焙坊操作台旁，中景包含双手、烤盘和柜门。烘焙师双手把装好面团的烤盘推上身侧空架，盘底落稳后松开右手，左手仍轻扶盘沿。她用空出的右手拉开下方柜门，取出折好的干布。烤盘保持在架上，面团没有移动。
```

**原因与适用边界**

把“腾手”写进动作因果，避免一只手同时完成两项互斥任务。只追踪影响画面的持物关系，不必规定每根手指；用户锁定单镜时，交接也应在该镜头可理解地完成。

## 2. 为同一个关键动作只保留一次发生

**判断步骤**

先把关键动作分成准备、接触、结果，标记切镜发生在哪一阶段。下一镜从该阶段继续；不可逆变化发生后，后续镜头保留结果，不重做起手或重复触发声音。

**易误写**

花艺师剪断一枝花，切到特写再次合拢剪刀剪下同一枝花，随后完整花枝又回到手中。

**原创可用写法**

```text
0—2秒，中景。花艺师左手固定花枝，右手将剪刀张开，刀口停在叶节下方。2秒切到手部特写，接同一次修剪：刀口继续合拢，只发出一次剪切声，短枝落在台面。随后回到中景，她拿起已经修短的花枝插入瓶中，剪下的短枝仍留在原处。
```

**原因与适用边界**

“换角度”不等于“再发生一次”。明确保留哪一个结果，比重复写动作名称更容易衔接。重播或多次操作只有在用户确有此意时才设计，并写明次数及叙事用途。

## 3. 让身体、道具和相机都有实际通路

**判断步骤**

确认人物脚下支撑、手臂或道具的活动范围、附近障碍和目标位置；再确认相机起点、路径、落幅。动作或运镜经过的区域必须可用，不能靠穿过台面、墙体或主体完成转换。

**易误写**

快递员背着宽纸箱穿过窄门，相机从柜架之间环绕一整圈，人物与货架位置都不调整。

**原创可用写法**

```text
快递站门口的侧面全景，空推车停在门外右侧。快递员先把宽纸箱放稳在推车上，再侧身跨过门槛，双脚落在室内地面后走向签收台。纸箱仍在门外推车上。相机留在门外左侧短距离横移，用门框交代进出位置，不绕入门后货架占据的空间。
```

**原因与适用边界**

支撑与通路决定动作是否能成立；相机同样受场地限制。幻觉空间或超现实穿越可另行设定，但应明确是创作效果。无必要时不用厘米级距离，能看清可通过与不可通过即可。

## 4. 把素材中要继承和要重建的部分分开

**判断步骤**

查看输入后分别确定：保留的外形或材质、允许变化的状态与角度、需要补建的空间，以及不能由当前视角确认的信息。参考背景不是必须继承的布景，未见反面也不能称为已知事实。

**易误写**

照抄产品照片的白色背景，同时要求它置于深色影棚；声称背面接口与原图完全一致，但原图只显示正面。

**原创可用写法**

教学假设：已查看图A，只能确认一台圆角奶白色磨豆机的正面、左侧旋钮和深灰接粉杯；背景为白色，背面不可见。用户允许重新布置场景，只需展示正面与侧面。

```text
深灰影棚内，奶白色磨豆机立在稳定展台上，保留参考图可见的圆角机身、左侧旋钮和深灰接粉杯，不继承原照片的白色背景。相机从正面缓慢移至左前侧，以机身边缘的透视变化呈现体积。画面不转到尚无依据的背面，也不新增接口或标识。
```

**原因与适用边界**

把已知外观与新构图分开，能避免复制背景或伪造产品细节。若任务必须展示未见区域，优先取得补充素材；用户允许虚构补建时，可明确采用创作版本，但不称其与实物一致。

## 5. 区分同一身份的不同状态

**判断步骤**

先确认多个输入是否属于同一主体，再分别记录稳定身份、当前外观状态、允许改变的项目和触发变化的事件。没有变更事件时沿用当前状态；已有变更事件时不能被“全程服装一致”一类泛化要求覆盖。

**易误写**

室外快递员穿雨衣，下一镜室内突然换了一张脸；或写“雨衣全程不变”，同时要求他已经脱下雨衣。

**原创可用写法**

教学假设：已查看两张参考图，确认图A的雨衣快递员与图B的灰色工作衫快递员为同一个人，两图提供不同穿着状态。实际使用时仅绑定相应场景需要的真实素材。

```text
快递站门内中景，同一名短发快递员穿着湿雨衣停在挂钩前。他拉开拉链，将两只袖子先后退出，把雨衣挂到门旁，露出里面的灰色工作衫。面容、发型和体态保持，雨衣留在挂钩上。镜头结束时他穿工作衫走向操作台，不再穿回雨衣。
```

**原因与适用边界**

身份连续并不要求服装永远不变。若图片是否同人不能确认，不自行合并身份；年龄变化、伪装或换装也必须来自用户内容或已说明的创作安排。

## 6. 区分固定个体与背景群体

**判断步骤**

先找出承担对白、连续动作或后续反应的固定个体，再确定背景群体是否只负责规模与气氛。有明确人数时说明固定角色是否计入总数；需要扩展群体时延续服装和行为基准，保留自然差异。

**易误写**

要求六名花店工作人员，画面中六名背景员工之外又加一名店主；所有人复制同一张脸并同时做相同动作。

**原创可用写法**

```text
花店开业前的全景，店内共六名工作人员，包含靠窗检查订单的店主。店主佩戴深绿色围裙，下一镜仍由她与顾客交谈。其余五人分散在包装台和花架旁，分别整理纸张、搬空桶、修整叶片；衣着同属朴素工作服，但面容、站姿和动作节拍各有差异。主要通道留空。
```

**原因与适用边界**

保持有叙事任务者的身份，匿名背景无需逐个编履历。人数只在用户明确要求或动作关系需要时固定；人物很远时写队列或活动节拍，不要求同时看清每张脸。

## 使用前复核

只保留当前镜头真正需要的细节：手是否可用、物体由谁支撑、动作是否已发生、当前主体是哪种状态、素材中哪些信息确实看过。发现冲突先调整顺序、机位或交接方式，不靠继续叠加“一致、准确、真实”等词解决。
