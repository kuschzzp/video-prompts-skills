# 光影与色彩设计

需要设计光源、明暗、色温、材质表现，或检查跨镜光线时读取。先保留用户的画面风格与约束，再补影响表达的细节；简单场景无需填写完整布光表。下述写法是创作意图，不是已经设置的灯光或生成参数。

## 从要看清的信息选择光

先判断观众此刻需要辨认什么，再描述光怎样帮助看见。按需选取下列信息，不要求每镜写全：

| 判断 | 写进提示词的内容 |
| --- | --- |
| 来源与位置 | 窗、灯具、屏幕、反射面等在场景中的位置；可见灯具是否亮着 |
| 方向与覆盖 | 光照到人物或物件的哪一面，哪些区域留暗；方向以场景位置为依据 |
| 软硬与明暗关系 | 阴影边缘的过渡、主体与背景的亮度关系、是否需要补光 |
| 色彩与材质 | 可见的冷暖或色彩差异，表面如何反光，是否遮住关键信息 |
| 变化与触发 | 人物走入光区、门打开、灯被关闭等，变化从何时开始、影响哪里 |

光源可以有多个；按它们各自的作用组织，避免互相矛盾的方向。阴影既能隐藏信息，也能刻画形体；不要为了“完整布光”照亮所有区域。

## 分清软硬、影长与曝光

- 光的软硬主要表现为阴影边缘过渡，与光源相对于主体的有效大小有关。大面积漫射或反射光通常更柔；小面积直射光通常更硬。亮度强弱不等于软硬。
- 影长取决于光源、物体与承影面的几何关系。硬光可以产生短影，软光也能产生较长的模糊影；室内长影不能直接证明时间晚。
- 低调画面通过暗部占比、明暗反差等组织注意力，不等于欠曝或关键信息必须不可见。高调画面也不等于过曝、没有阴影或只适合白天。
- 需要看清暗处细节时，可调整受光、反射、景别或构图；若隐藏细节本就是叙事目的，保留该选择。尺度与焦点另见 [视觉与空间](visual-continuity.md)。

## 色温、调色与混合光

画面冷暖受光源、环境反射、白平衡与调色共同影响。荧光灯、LED 和屏幕不必然偏冷，白炽灯也不必然在成片中显黄；具体描述观众看到的结果，不凭灯具名称代替判断。

混合光可保留不同区域的色彩差异，也可统一到接近的色彩基准。写清差异落在哪里，以及需要保留的肤色、产品色或其他识别信息；不要求所有光源冷暖一致。

调色板按题材和用户风格选择，不固定颜色数量、饱和度或主辅色比例。同一场景可通过构图和人物移动改变色彩占比；有意的调色变化也可以服务表达，需交代变化时段与目的。

暖光、冷光、逆光等没有固定情绪含义。时间、天气帮助解释自然光，但夜间可以明亮，白天也可以昏暗；日落时刻需结合地点、季节或用户设定，不从一个钟点推断天色。

## 材质与反光的可读性

布、木、墙面和金属都会反射光，差别在表面、颜色、粗糙度和观察角度。布料可能有柔和反射或丝质亮斑，粗糙金属也未必有清楚的镜面倒影。

反光能展示质感，也可能盖住文字、面部或接触位置。重要操作先保证可见，再安排亮斑与氛围；不要靠反复添加“清晰”抵消遮挡。雾、烟、雨尘按场景需要使用，可以共存，不为展示光束凭空增加。

## 跨镜连续性与亮灭动因

- 保持灯、窗和主要反射面的场景位置一致。反打时屏幕左右可改变，持续的是光源与对象的空间关系，不是某侧画面永远更亮。
- 人物转身、走位或物体移动会改变受光与投影；接续镜头承认已经发生的变化，不把动作后的状态重置。
- 交代灯为何亮灭、光区为何移动。灯关后仍有窗光或其他照明时，可保留相应亮度，不机械把整个房间变黑。
- 表现时间流逝时，按需要关联天色、自然光或实际时钟；单次调光也可能只是人物操作，不自动解释为时间跳转。

## 原创短例：辨认织补处

虚构场景：午后裁缝工作台，人物需要确认一件深色外套的织补处。以下只示范光与动作的关系，不是完整提示词或模型效果保证。

易误写：“低调氛围，布料不反光，所有黑色细节都清楚；切反打后光仍从画面左侧来。”

可用写法：“午后，工作台靠北侧窗，漫射日光照着外套。裁缝将织补处移入窗边亮区，侧向受光显出细小针脚；背景保持较暗。切到桌子另一侧近景，接同一次移布后的状态，窗的位置不变，衣料上的明暗随机位合理变化。”

这段通过受光和机位让针脚可读，不把低调等同于看不清，也不为换机位移动窗户。若用户指定更抽象的风格，围绕该风格重新选择表达。
