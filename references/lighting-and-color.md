# 光影与色彩设计

设计镜头时使用。光不是“亮一点”或“自然光”四个字，而是实际光源、方向、软硬、色温和时间。本文件只教怎么写进提示词，不把光线写法当成模型已设置的参数。以下例子均为原创教学材料，不构成固定剧情或模型能力证据。

## 先定光源，再定情绪

每镜先回答四个问题，写进正文只留观众能看见的部分：

| 问题 | 写什么 |
| --- | --- |
| 光从哪里来 | 窗、台灯、顶灯、门缝、电视机，写一个主光源，不要同时列三个“主光” |
| 光从哪个方向来 | 侧光、逆光、顶光、正面光；方向决定脸和物体的哪一半在阴影里 |
| 光是硬是软 | 硬光边缘清楚、影子长；软光过渡平缓、影子淡；窗纱、阴天、灯罩都会把光变软 |
| 现在是什么时间 | 清晨、正午、黄昏、深夜；时间决定色温和亮度，也决定窗外是亮还是暗 |

光的情绪效果取决于上下文。不把“暖光必然温馨”“冷光必然孤独”当规则；同一盏暖黄台灯，既可以是等人回家的灯，也可以是舍不得关的灯，区别在人物在灯下做什么。

## 色温：暖与冷的对照

色温写成可观察的对照，不要只写“暖色调”。

- **暖光**：台灯、白炽灯、烛光、黄昏余光。写“暖黄台灯从侧面打过来，表盘反一点光”。
- **冷光**：暮色、阴天、荧光灯、屏幕光。写“窗外是蓝灰色暮色，冷光从背后进来”。
- **对照**：同一画面里暖冷并存时，写清交界在哪里。“暖黄台灯光和冷蓝暮色光在墙上交界，挂钟的影子很长。”交界本身就是信息：屋里有人等，屋外天已黑。

易误写：全片“暖色调、温馨”，同时要求窗外正午阳光和深夜台灯并存。
可用写法：先定时间是傍晚 7:42，再定窗外蓝灰、屋内暖黄；后续镜头不再改时间，除非写清时间已过去。
为什么：色温来自光源和时间，不是后期滤镜。时间一改，光源、亮度和窗外都得跟着改。

## 低调与高调：画面有多暗

- **低调**：画面大面积暗，只留一处亮。适合等人、守夜、只剩一个物件的场面。写“低照度，只留台灯一处暖光，门在背景里虚着”。
- **高调**：画面整体亮，阴影淡。适合白天、明亮的工作间、开阔的外景。
- **不要**：要求“低调氛围”又要求“所有细节清晰锐利”。暗处的细节本来就看不清，看不清才是低调成立的条件。

## 实用光源与影子

台灯、蜡烛、电视、路灯都是画面里的实物，既是光源也是道具。写实用光源时写清它在画面里的位置和状态：灯开着还是关着，光照到哪里，影子落在哪里。

- 易误写：台灯在画面左，脸的受光却在右；或灯关着，房间却很亮。
- 可用写法：“台灯在木桌左侧开着，暖光照着老头的手，影子拉在木桌上。”
- 影子是光的证据：手抬起来，影子跟着动；挂钟的影子长，说明光低、时间晚。

## 大气与材质

空气里的东西决定光看不看得见：灰尘、雨雾、烟、蒸汽。写大气只写一种，不要同时写“尘土飞扬又空气清新”。

- 灰尘：侧光里看得见，适合老房子、久不住人的房间。写“侧光里有一点浮尘”。
- 雨雾：适合窗外、夜路。写“窗外雨丝反着路灯的光”。
- 材质：木桌磨得发亮会反光，墙皮剥落会吸光，金属表盘会反光，布面不会。写材质就是在写光怎么落在它上面。

## 调色板：先定三到四个颜色

每片先定一个调色板，全片共用，不每镜换一套。

- 可用写法：暖黄、灰蓝、暗木色、泛黄的表盘。色彩偏暖黄加灰蓝，不鲜艳。
- 易误写：每镜都加一个新颜色，红、绿、金、粉全有，画面没有主色。
- 为什么：调色板是连续性的一部分。换场景可以换调色板，同一场景换调色板需要时间或灯光变化作依据。

## 光如何承载意义

光要服务信息，不是装饰。问一句：这镜的光让观众看清了什么新东西？

- **可读性**：关键细节必须有光。表盘停在 7:42，表盘上就得有光；否则观众看不见数字，反转不成立。
- **对照**：停了的手表和走着的挂钟，一个在暖光里，一个在冷光和暖光交界处，观众先看见对照，再去想意思。
- **变化**：光变了，时间就变了。台灯从亮到暗、窗外从蓝到黑，都是时间在走的证据，不用旁白说“时间过去了”。

### 原创例：黄昏的表

以下为本 skill 新编的原创练习《7:42》，不是任何创作者的原作复刻，只用来说明光怎么写。

虚构条件：傍晚 7:42，老房子客厅，一只旧手表停在 7:42，墙上有挂钟，门在背景里。

- 易误写：“自然光，安静。”——没有时间、没有光源、没有方向，生成时光从哪里来全凭运气。
- 可用写法：“傍晚 7:42，窗外蓝灰色暮色，屋里只有一盏暖黄台灯，低照度。台灯暖光从侧面打在手表上，表盘反一点光；挂钟在暖冷交界的墙上，影子很长。”
- 为什么：时间、光源、方向、色温、影子都在一句话里，观众能看清表盘，也能读出屋里屋外是两个世界。

## 写进提示词时保留必要信息

用“时间—主光源—方向—色温对照—关键细节受光”组织一句或一段自然中文。不写色温数值、灯具型号、曝光参数，不声称平台已设置某一路灯光。用户给出精确参数时尊重并检查相容性；未给出时用可判断的相对变化表达。

跨镜检查光源连续性：灯的位置、窗的方向、时间的早晚在各镜里保持一致；换到反向机位时，屏幕左右的明暗可以合理改变，不能机械要求某一侧脸永远受同样的光。详见 [视觉与空间](visual-continuity.md)。

## 常见误用

| 误用 | 改法 |
| --- | --- |
| “自然光”四个字打发全片 | 写清时间、窗的方向、主光源是什么 |
| 暖冷同时最强，画面没有主色 | 先定一个主色温，另一个只作对照 |
| 要求暗处所有细节都清晰 | 暗处看不清是低调成立的条件，改景别或加一盏灯 |
| 灯的位置和受光方向对不上 | 先定灯在画面哪一侧，再写脸和手的受光 |
| 每镜换一套调色板 | 同一场景共用调色板，换调色板要有时间或灯光依据 |
