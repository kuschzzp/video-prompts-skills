# 物件线索与意义变化

仅在本任务已选择用物件贯穿表达，或用户明确希望设计意义翻转时使用。物件可以帮助观众理解人物和关系，不必成为主角。其他创作仍按 [导演决策](directing-and-performance.md) 选择适合内容的组织方式。

本文件提供可选方法，不规定故事结构。允许无对白、无反转、以人物为主体；不要求问句开场、三拍、两人一景、金句、物件结尾、字幕或旁白。用户的原文、剧情、节奏和结尾优先，未获授权不为套用方法改写。

## 先判断物件为什么值得被看见

- 它与当前人物的行动、关系或选择有什么联系？只保留剧情已有或用户允许补充的信息。
- 观众第一次看见它时，实际能知道什么？不要用作者知道的身世替代画面证据。
- 它再次出现时，增加了什么信息？没有新的作用就不必重复特写。
- 重要变化来自物件状态、人物使用方式，还是观众后来知道的背景？先分清，再安排镜头。

可以在内部简记以下关系，不要求输出制作表：

| 层次 | 要判断的内容 |
| --- | --- |
| 实际状态 | 物件在哪里、由谁持有、是否已发生变化 |
| 可见证据 | 当前机位能看见哪些材质、使用痕迹或接触动作 |
| 观众认识 | 此刻依据画面知道什么，哪些信息仍未显露 |
| 人物回应 | 新信息是否影响动作或选择；没有影响时不硬添反应 |

## 让认识变化有画面依据

可通过使用、交接、修补、位置变化或后续情境，让同一物件获得新的含义。选择内容需要的方式即可，不必让前后理解互相对立，也不以观众是否争论判断作品是否成立。

需要翻转时，前一理解应有依据，后一理解由新增证据支持；不要靠突然补出的亲属关系、遗言或人物身世完成翻转。用户未要求翻转时，物件也可以维持原来的意义，仅承担行动线索或情绪延续。

可以先让人物与物件同框，再按可读性决定是否切近景。固定镜头中的动作、显露或视线同样能够提供新信息；不因物件重要就强加推镜、拉焦或特写。

## 保持物件与动作连续

只记录影响剧情的状态：放置点、持物手、接触阶段及必要外观。镜头显露某物，不等于它刚刚出现；意义变了，也不等于材质、数量或位置变了。

物件跨镜、跨片段出现时，补足当前段需要的初态与身份锚点；交接、腾手、承重及素材职责按 [动作与素材](action-and-assets.md) 检查。不为突出象征意义省略实际动作前提。

## 原创短例：旧饼干盒

虚构条件：修理铺整理工作台，一个旧饼干盒被放在待清理物品旁。师傅打开盒盖，从已分好的垫片中取出一枚；学徒看见后，把盒子移回工作台。

可用处理：先用同框画面交代盒子的位置与两人的整理动作；打开时让内部分类可读，随后接取出垫片和移回盒子的同一次行动。观众从“可能被清理的包装盒”认识到它仍有用途，无需新增台词、字幕或旁白解释。

也可以始终让观众知道盒子是收纳盒，只关注两人如何配合整理。是否保留认识变化，由这次作品的表达目的决定；这个短例不规定用户故事的情节或结尾。

## 交付前只检查本次选择

物件是否服务已有内容，重要信息是否在当前尺度可读，前后状态是否连续，新增解释是否有依据。未选择物件表达的任务无需通过本文件的检查，不因此重写原文。
