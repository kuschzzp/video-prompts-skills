# 以物件为先的故事结构

原创短片创作时使用。不是所有题材都适用；文学改编仍按主文件保留原文事件与关系，不强行套用本结构。本文件只提供一种可选的短片骨架：一个日常物件先行，意义在中途翻转，结尾留白。以下例子均为原创练习，标注“练习”的都不是任何创作者的原作复刻。

## 骨架

1. **一个日常物件做主角**：选一个随手可得、真实用过的东西——手表、苹果、一杯水、一把伞、一根棍子。物件要具体：材质、磨损、颜色、状态都能写出来。不要选抽象概念，也不要选只在台词里出现的东西。
2. **一个反差物作对照**：能走的表对停了的表，新电子表对旧手表，熟透的苹果对酸苹果。反差物只出现一次，用来衬出主角物件的不同，不抢主角的位置。
3. **问句开场，不说结论**：第一句是一个看着天真的问题——“表都停了，还戴着干嘛？”“这甜苹果怎么是酸的？”问题本身就是全片，观众带着问题看下去。不要开场就说“这是一个关于等待的故事”。
4. **三拍，只写动作和物件**：发展写三拍，每拍只写看得见的动作和物件，不写心理、不写“他很想念她”。人物最多两人，场景只有一个。动作要能接起来：拿起、放下、戴回、看一眼、对上。
5. **中途翻转，两种解读都成立**：同一物件在后半段读出第二个意思，两个意思正好对立，观众可以各执一端。翻转不是剧情反转——世界里什么都没变，只是描述变了。观众要能吵起来，而不是只会同情。
6. **全片只一句金句，放在后半段，只讲物件**：金句讲的是物件本身的道理，不是人物的心情。其他台词只谈物件。金句一出，片子就收住，不再解释。
7. **结尾停在物件上，留白**：最后一个镜头停在物件本身，不交代人物结局，不加旁白，不加解释字幕。观众自己决定是什么意思。

## 两种解读要真对立

翻转成立的条件是两个解读互相顶着，都有道理。

| 写法 | 效果 |
| --- | --- |
| 坏表对停住的时间 | 不对立。后一种只是前一种加了点伤感，观众只会同情，不会争论 |
| 束缚对归宿（鸟笼） | 对立。同一只笼子，有人看到关住，有人看到回家 |
| 熟透的甜对留得住的甜（苹果） | 对立。立刻的甜和留得住的甜不能同时要，选一个就得放弃另一个 |
| 坏表对一天里只有这个时刻说真话（手表） | 对立。扔了是省事，留着是每天等一个准的时刻 |

检查方法：把两个解读写成两句话，问一句“观众会不会为这两句吵起来”。只会点头的不是翻转，只会掉泪的也不是翻转。

## 人不抢物件的位置

“句句不提人，句句不离人”：人物关系从不直接说出来，观众从物件里自己补。

- 易误写：老头在等她，表只是他伤心的证据。故事一下变成“痴情老头”，一眼能猜到结局。
- 可用写法：老头只做三件事——接过表、戴回去、看一眼挂钟。等不等她，观众自己从动作里读。
- 为什么：物件在中心，人在旁边。人物一成主角，物件就成了道具，翻转也就没了着落。

## 金句只讲物件

- 易误写：“7:42，她该回来了。”——直接把等待点破了，观众不用想了。
- 可用写法：“停了的表，一天也能准两次。”——只讲表，不讲人的心情。观众想一想才明白，准两次是什么意思。
- 检查方法：把金句里的人名、人称、心情词都去掉，剩下的还成立吗？成立，才是讲物件的金句。

## 填好的练习：《7:42》

以下为本 skill 新编的原创练习，不是任何创作者的原作复刻，只用来示范骨架怎么填。编剧锚点只写作者自己知道，片子里不说。

- 核心物件：一只旧手表，表带磨得发亮，表盘泛黄，停在 7:42。
- 反差物：一只崭新的电子表，能走的时间。
- 人物：头发花白的老头；来收拾屋子的年轻人。最多两人。
- 场景：老房子客厅，一张旧木桌，墙上有挂钟，门在背景里。只一个场景。
- 开场问句（字幕，不出声）：“表都停了，还戴着干嘛？”
- 三拍，只写动作：
  1. 年轻人拿起桌上的旧手表，翻过来想看表背，表盘停在 7:42；顺手看了一眼手机上的时间，把表放回桌上，像是要收起来扔掉。
  2. 老头伸手接过手表，戴回自己手腕上，手指擦了一下表盘，眼睛看了一眼墙上的挂钟。挂钟走到 7:42，表盘上的 7:42 和它对上了——停了的表，这一秒是准的。
  3. 年轻人也看了一眼挂钟，又看了一眼老头手腕上的表，没说话，把表盒轻轻推到一边。
- 意义反转：第一次，坏表，该扔；第二次，一天里只有 7:42 这一刻，它说的是真话。
- 点题金句，全片只一句：“停了的表，一天也能准两次。”
- 结尾：镜头停在那只手表上，秒针不动，挂钟继续走，门没开。不交代她去哪了，不交代老头等了多久，不交代 7:42 是谁。

## 空白自查表

填完一个原创短片后，逐项打勾。有一项不成立，就先改剧本，不写分镜。

- [ ] 核心物件能不能一句话说清材质、磨损和状态？
- [ ] 开场是问句，还是已经把意思说出来了？
- [ ] 三拍是不是只写动作和物件，没有心理描写？
- [ ] 两种解读是不是真对立，观众会不会吵起来？
- [ ] 人物有没有抢物件的位置？
- [ ] 金句是不是只有一句，是不是只讲物件？
- [ ] 结尾是不是停在物件上，没有旁白和解释字幕？

## 不做的事

不强行添加冲突、三幕或反转；不让角色 narrate 自己的心情；不加第三个解释者；不加多余的人物和场景；不搞大剧情反转；不让物件离开画面。以上有一项出现，骨架就塌了。
