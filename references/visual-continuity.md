# 视觉设计与连续性

本文件帮助判断画面中的细节能否读到、机位与运动是否成立，以及镜头和生成片段如何衔接。按任务读取相关章节；简单镜头无需填写全套表格。以下例子均为原创说明，不是固定剧情或完整提示词。

先选方法再查可行性：景别、构图、相机运动与焦点变化的选用见 [经典镜头与运镜](camera-language.md)，视点、轴线、场面调度和剪辑关系见 [镜头组织与剪辑](editing-and-staging.md)。这里不要求所有镜头都移动或都遵循同一种构图。

## 从关注对象建立场景锚点

先确定本镜观众需要看清谁、什么动作或什么关系，再选择必要的视觉锚点：空间布局、固定地标、人物外观、主光来源、材质与色彩。只保留影响理解和连续性的特征，不为每件背景物编造数量与参数。

把场景当作持续存在的空间。人物背后有什么、入口通往哪里、物体靠哪面墙，都不会因为切镜自行改变。需要时先在内部写清人物、目标、障碍和摄影机的相对位置，再把本镜看得见的部分写进正文。

设备或胶片名称可以表达偏好，但不能替代画面关系。柔焦光晕不等于眼睛失焦；浅景深也不能使关键操作失去可见证据。

## 景别决定哪些细节可读

先看主体在画面中有多大，再判断要求观众识别的细节是否成立。远景适合交代路径、人与空间的比例和群体关系；近景适合眼神、口型、细小手势和操作接触。景别名称只是起点，遮挡、对比、焦点和运动速度同样影响可读性。

关键细节太小时，优先调整机位、景别或动作位置；确实需要同时交代环境和操作时，分配到能衔接的镜头。不要靠“清晰可见”要求极远处的微小表情，也不要为看清细节无理由改变物体的真实大小。

- 易误写：俯拍整座图书馆，一名小小的馆员在书架间核对书脊编号，观众读清每个数字。
- 可用写法：俯拍先交代馆员与目标书架的位置；切到她手边的近景，手指停在需核对的书脊旁，编号落在焦点范围。
- 原因：空间关系和文字识别需要不同的观察尺度。切近景承接核对动作，不让人物重新走一遍路线。

## 当前机位决定应见背景

每次切镜或改变朝向，都重新判断镜轴指向哪里、主体后方是什么，以及哪些对象应留在画外。正反打保持可理解的视线关系；同一个地标不必出现在所有方向的镜头里。

区分世界中的方向与屏幕左右。人物转身、反向拍摄或跨轴后，屏幕位置可能改变；连续性应以固定地标、人物距离和相互朝向为依据。需要跨轴时，用能重新交代空间的取景或连续运动使观众理解变化。

- 易误写：馆员面向入口站着，正面近景和背后反打都把入口放在她身后。
- 可用写法：正面近景从入口一侧拍向馆员，后景是阅览窗；反打从阅览窗一侧看向她的背影，入口出现在前方。
- 原因：摄影机换到另一侧，所见背景也应改变；入口位置保持不变，改变的是观察方向。

## 把主体运动与摄影机运动分开判断

复杂运镜先在内部区分三件事：主体相对场地怎样移动；摄影机在哪里、如何跟随；两者关系使主体在画面中怎样位移或变大变小。最后检查背景视差、地面纹理和衣物响应是否支持同一种运动。

固定焦段且保持相对距离跟随时，主体可以在画面中相对稳定，但场地仍应从其周围经过。摄影机停下、主体继续远离时，主体会逐渐缩小；摄影机靠近而主体没有远离时，通常会扩大。镜头变焦也会改变取景尺度，应说明是否使用，不能把它与机位移动混为同一效果。

- 易误写：固定焦段，摄影机与滑板者同速侧向跟拍，距离始终不变，滑板者很快缩成远处小点。
- 可用写法：固定焦段，摄影机沿场边与滑板者同速平行移动，人物保持近似大小，地面分隔线向后掠过；到坡道前摄影机停下，滑板者继续滑远，身影才逐渐缩小。
- 原因：主体的屏幕变化来自相对运动。分清摄影机何时跟随、何时停住，就能避免互相抵消的运动要求。

## 摄影机需要可通行的路径

连续移动前检查起点、终点与中间路径，确认有门口、通道、足够的转弯空间和可用高度。前后两个机位各自成立，不等于摄影机能在两者之间连续穿行。先解决障碍，再决定推、拉、侧移或环绕。

普通写实镜头不穿过实体墙、封闭柜体或人体。路径受阻时可缩短运镜、换到通道侧、等待可见开口，或切镜到新机位。用户明确要求超现实穿越或特殊视效时保留该创作选择，并说明它属于特殊镜头设计。

- 易误写：摄影机从馆员背后连续前推，穿过整排封闭书架，停在隔壁通道的读者面前。
- 可用写法：摄影机从馆员背后沿通道前移，到书架端头停住；切到隔壁通道的读者近景，来向由同一书架端头交代。
- 原因：书架挡住实体路径。通过端头建立空间联系，再切镜换位，比把阻挡写成不存在更容易形成可信画面。

## 遮挡与信息揭示

先区分两种变化：对象在场景里发生了变化，或对象一直存在而观众现在才看见。移开前景、打开门、换机位和转移焦点可以揭示信息，但不应无故改写物体的生成、位置和状态。

为重要揭示写清遮挡物、被挡对象和解除遮挡的动作。前景可以建立纵深和观看方向，但不能持续遮住唯一需要辨认的接触点。若必须隐藏关键过程，应有叙事目的，后续画面也应承认观众尚未看到过程。

- 易误写：库房门向内打开，门后突然生成一辆装满书的推车。
- 可用写法：装书推车一直停在库房侧墙旁，被关闭的门挡住；门打开后，推车从门扇边缘逐步显露，轮子仍在原位置。
- 原因：这是可见范围发生变化，不是推车在世界中刚刚出现。先确定其原有位置，就能约束揭示前后的状态。

## 光线与画幅转换

光线说明实际来源、方向、软硬和必要的变化。连续性按灯、窗和反射面判断；换到反向机位时，屏幕左右的明暗可以合理改变，不能机械要求某一侧脸永远受同样的光。新增光源或曝光变化需有画面依据。

- 易误写：馆员绕阅览桌走到窗边，摄影机反打后，仍要求同一侧屏幕始终出现窗光和窗外背景。
- 可用写法：窗户固定在阅览桌东侧；各机位分别保留面向窗户一侧的受光与桌面的反光，背景随拍摄方向重建。
- 原因：持续存在的是光源，不是某块亮面在屏幕中的固定位置。

改画幅时先检查人物能否同框、交互部位会不会被裁，以及背景中哪些地标仍需保留。可以调整取景距离、机位或站位，但不能暗中改变用户指定镜头或添加字幕区；必要差异需简短说明。

- 易误写：把横幅中的两人远距离递工具原样改成竖幅，两人的手仍全部在画内。
- 可用写法：竖幅改用斜侧中景，把检修员与同事安排在画面前后层次，递出的工具和两人的手留在中部。
- 原因：前后错位能利用画面纵深保留交互；若用户锁定原站位，则应说明无法同时保留全部内容，而不是悄悄挪人。

## 镜头交接与独立片段

只追踪剧情重要的状态。可在内部记录以下项目，普通镜头不强制展示表格：

| 对象 | 需要核对的进入与离开状态 |
| --- | --- |
| 人物 | 身份、服装、位置、朝向、视线目标 |
| 手与道具 | 持物手、必要数量、接触状态、放置点、动作阶段 |
| 空间 | 机位所在轴线侧、背景地标、人物距离与可通行路径 |
| 光线 | 实际光源、时间或天气、曝光与色彩基调 |
| 声音 | 持续底声、未完对白、动作音是否已触发 |

切镜接同一次动作已经到达的阶段，不为新镜头重新起手。下一生成片段从上一段留下的状态继续；时间或场景跳转需有叙事依据。片段结束可以保留持续动作，不要求每段都停成静止姿态。

- 易误写：馆员把退回的书放上推车；切近景后，书又回到她手中，重新放一次。
- 可用写法：中景拍到书落稳；近景接她松开书脊的手，随后将推车向通道内推去。
- 原因：切镜改变观察位置，不重置事件。交接点应包含“是否已经接触、是否已经放手”。

每段代码块重复本段需要的人物和场景锚点、已确定设置及关键初态，不用“同上”代替可复制正文。保持角色身份与说话人编号稳定；声音需要跨段延续时，分别写清上段退出和下段进入的状态，不假设独立生成会自动连续。

## 参考图与目标状态

先区分素材职责：外观、服装、场景、构图、动作阶段或首尾帧。一张图可以兼任多种职责，但只在相应时段约束动作状态。图像提示词只画一个时刻，与视频共用必要的人物、场景和光线锚点，不混入整段切镜、对白与先后动作。

- 易误写：参考图是检修员已经关好设备盖的姿态，既要求把它作为首帧，又从盖子敞开、手伸入内部开始写。
- 可用写法：把该图设为结尾姿态参考；开场另用盖子敞开的画面。目标模式只能接收首帧时，说明需要另备开场图或调整动作路径。
- 原因：身份可以贯穿全段，图中动作状态却只对应一个时刻；参考构图也不自动等于工具提供的尾帧锁定。

片尾精密交互先保证接触路径与落点可见，再选择运镜。需要准确图像落定时核对目标模式；若建议插入静帧，说明它会冻结自然运动，且未经用户授权不实际改动视频。

素材编号按每次实际输入核对。同一人物使用不同素材编号时，身份描述仍需一致。计划把上一段末帧作为下一段首帧时，先标明输出依赖；取得真实输出、查看其状态并确认模式支持后才能绑定。文本方案不能声称已经取得末帧或保证无缝衔接。

## 写完后的快速核对

逐镜看一遍：关键信息是否处于可读的尺度与焦点；当前机位能否看见所写背景；主体与摄影机的相对运动是否成立；路径是否被实体阻断；新看见的对象是否有连续的位置和状态。

再接着看相邻镜头和片段：动作有没有重做，持物与朝向有没有重置，光线是否来自同一来源，下一段能否凭自己的正文恢复必要上下文。只修正与当前任务有关的问题，不为简单画面补满无用细节。
