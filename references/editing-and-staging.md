# 视点 调度与剪辑选择

需要安排观众注意力、组织对话、建立空间或连接时空时选读。先决定信息关系，再选择技法；不用术语数量、固定情绪含义或每15秒镜头数衡量质量。以下均为原创虚构教学片段，不依赖外部素材或特定工具参数，实际交付仍按主文件补全单段设置、时间与正文。

## 1. 主观视点 客观观察与限制信息

**触发与判断步骤**

先判断此刻观众应与谁共享信息，是否需要看到人物尚不知道的内容。主观镜头将观察位置放在人物眼睛附近，展示其当时所见；客观观察可以同时交代人物及其周围。限制信息也可用景别、遮挡和画外空间实现，不必全程主观。

**原创可用写法**

```text
天文馆圆厅内，孩子的侧面近景：他听到投影机启动，抬眼望向上方。切到与他抬头方向相符的仰视画面，圆顶上第一片星点逐渐亮起。再回孩子近景，他的目光随光点移动。工作人员此时仍在画外，直到下一镜孩子转向控制台，才看见她已经站在那里。
```

**误用边界**

第一人称叙述不自动等于主观摄影；贴脸近景也不是人物所见。若镜头显示观察者身后的秘密，就已超出该人物的即时视野。新信息首次入画不等于对象刚生成，遮挡期间也要保持世界状态。

## 2. 正反打 过肩与反应镜头

**触发与判断步骤**

对话先确定谁的表达或反应值得看，再选择两人同框、单人正反打或过肩。过肩要说明从谁肩后看谁，以及肩部占位；正反打是镜头间的对应组织，不要求每镜都有肩膀。台词可连续覆盖听者反应，无需每一句都切回说话者。

**原创可用写法**

```text
社区厨房领餐台的双人中景，志愿者与第一次来的居民相对站立。志愿者指向空位，开始介绍取餐流程。切到居民近景，介绍声从画外领餐台另一侧连续传来；他原本抓紧布袋的手放松，视线顺指示移向空位。居民准备回应时，再从志愿者真实肩后看他的脸，前景肩缘不遮住嘴和目光。
```

**误用边界**

画外说话者仍在当前场景中向别人说话；旁白是另一个叙述层，不能仅因人物没入画就把台词改为旁白。听者反应取决于所听内容，不给每句都加点头、落泪或惊讶。

## 3. 场面调度 深度构图与连续长镜头

**触发与判断步骤**

若重点是多人同时处于一个空间的关系，可让人物、道具和进出画承担注意力变化，而不立即切近景。先排前中后景及可通行路线，再决定相机保持、重构图或移动；关注从哪里转向哪里，必须有动作、声音或视线触发。

景别指主体在画面中的尺度，时长指镜头持续多久；远景不等于长镜头，近景也可长时间不切。单段15秒内需要保持连续时，直接说明全段不切镜即可，不把它当作所有电影语境下“长镜头”的固定时长定义。深度调度也不等于所有距离都必须清晰。

**原创可用写法**

```text
社区厨房内，一个不切镜的中全景。前景居民把空餐盘放到台上，中景志愿者接盘，后景另一名工作人员从备餐口端出新一盆食物。前景居民侧移一步让出通道，后景来人因此完整显露；相机只略微横摇接住她靠近，注意力从等待的人转到补餐完成的动作。关键交接保持可读，不要求远处所有标签都清楚。
```

**拉焦的选择**

若重点是同一构图中两个距离的关注交接，可保持画面不切、只改变清晰平面。例如会议筹备中先对准前景桌上的已整理座牌；门口传来脚步后，将焦点转到后景刚到的主持人，前景座牌变虚。若要看清微小文字，可改用合适近景，不能用拉焦保证远处细节必然可读。

**误用边界**

拉焦不是切镜，也不是移动主体；变焦、相机前移与拉焦不能混写。长镜头可静止，深度场面可用选择性清晰；需要观众同时比较多个层次时，才选择足够的景深与可读构图。

## 4. 轴线 视线匹配与动作匹配

**触发与判断步骤**

连续空间先找对话连线或主要运动方向，确定相机位于哪一侧。常规连续剪辑保持同侧以便理解左右关系；人物移动造成轴线变化时，先展示新站位。需要越轴，可用可理解的连续机位移动或重新交代关系的镜头过渡，而非无理由跳到反面。

视线匹配检查看者的方向、俯仰与目标位置；动作匹配检查切出、切入是否接同一次动作的相邻阶段。两者可同时使用，但不是同一个要求。

**原创可用写法**

```text
单车维修点的双人中景，车主在画左看向右侧维修员，摄影机位于工作台朝入口的一侧。切车主近景，他看向画外右下方的后轮；下一镜从对应观察方向拍后轮，维修员已将阀帽套到气嘴上，开始旋紧。切到侧面手部近景时，接同一次旋紧的后半程，阀帽沿原方向落稳，不重新从桌上拿起。
```

**误用边界**

180度规则服务空间理解，不是绝对艺术禁令。反向机位的背景和屏幕左右要重新判断；主观目标镜头也不能随意采用与人物位置不相容的高空视角。具体物体的承重和握持另查 [动作与素材](action-and-assets.md)。

## 5. 形状匹配与跨场景动作衔接

**触发与判断步骤**

在用户已允许的场景转换处，选择真正有意义的相似形状、构图位置或运动方向，比较前镜末幅与后镜起幅。形状匹配连接视觉相似性；跨场景动作衔接利用相近的运动节奏，不意味着两处物体相同，也不等于同一动作的连续剪辑。

**原创可用写法**

虚构前提：短片原本就由单车维修点转到稍后的天文馆参观，允许用圆形构图连接两个地点。

```text
前镜停在修好的前轮正面，圆形轮缘处于画面中央；硬切到天文馆圆形顶窗的对应构图，窗外的白昼让新地点成立。后镜缓慢下摇，露出圆厅和进入的参观者，明确已经换场，不把车轮变形成建筑。
```

若用动作呼应，可在前镜向右推开维修单夹后，接新场景中同向拉开入口隔帘的起幅；先确认这一安排符合原文，不能只为顺滑增添动作。

**误用边界**

不要把匹配剪辑写成必须发生的物体融化或变形；相似构图不证明时间连续。转场有跨镜重叠时，按实际重叠另算整片时长，不把两个动作的完整用时都塞进同一短切点。

## 6. 交叉剪辑 平行蒙太奇与省略

**触发与判断步骤**

先确认事件间的时间和因果。两条行动确实同时进行且相互形成等待、会合或影响时，可以交叉剪辑。若只是比较相似劳动或不同处境，可作平行并置，但不要暗示原文没有的同时性或因果。相关术语在不同教材中有重叠，正文应写清实际关系，而非只报技法名。

省略用来跳过不影响理解的重复步骤。先保留起始条件和结果，再用明确状态变化交代经过时间；不能省掉用户要求展示的动作、重要对白或改变人物选择的事件。

**原创可用写法**

```text
虚构前提是会前十分钟，两组工作人员正在同一时间做最后准备。会议室内，志愿者逐张摆正座牌；切走廊，另一组把最后一摞资料装上小推车；切回会议室，桌上空位尚未补齐，门外推车声逐渐靠近。最终回到两组在门口会合的全景，资料实际进入房间。
```

若原文是先摆座牌、再装资料，保留先后，不改成上述并行。若只需表达连续几天的维修工作，可选不同日期重复的登记、检查和交车画面并置；用明确的时间变化交代跨度，不制造“同时发生”的误解。

**误用边界**

交叉剪辑不自动等于悬念，平行并置也不必承担宏大隐喻。省略是表达时间的选择，不是隐藏剧情缺失的办法。所有镜头仍计入单段预算，超过预算就按主文件拆段；不以密集快切掩盖超载。

## 7. J-cut L-cut与声画关系

**触发与判断步骤**

先决定声音来自哪一场、谁能听见、何时开始结束，再决定音画切点是否错开。J-cut让下一镜或场景的声音先进入，画面稍后切换；L-cut让上一镜或场景的声音延续到新画面。声桥可连接空间或持续反应，不要求两个场景的画面叠化。

**原创可用写法**

```text
J-cut：画面仍在会议室，桌边志愿者收好最后一排座牌；走廊推车的轮声先进入。声音持续时切到走廊，来人推着资料车朝会议室接近，声源获得画面确认。

L-cut：维修员在中景说明检查结果。切到车主试捏刹把的近景，维修员的原句从画外同一方位连续说完；车主不跟着动嘴，车轮仍在原支架上。台词结束后保留刹把回弹的动作声。
```

**叙事声画对位**

声音也可补充或反衬画面，而不重复解释。虚构的会议筹备片中，可让画面留在已整理妥当的空讲台，画外对讲机传来仍在协调座位的工作声，使观众知道“画框内完成了，框外仍在忙”。该工作声必须属于已建立的活动，不用虚构警报强行制造紧张。

**误用边界**

声画对位不等于口型错位或音效不跟接触。人物现场画外声、内心声音和旁白分开标明；非同时的回忆声音要有叙事依据。跨生成片段的精确声桥若需后期完成，说明所需连续声音和相邻画面，不声称独立生成会自动接成同一音轨。
