## 模式与官方重写格式

基础模式选择：无素材为 T2VA；首帧为 I2VA；首尾帧为 FL2VA；仅尾帧为 L2VA。完整参考任务采用 Ref2VA。工具是否开放该模式另行核对。

官方重写模板中，基础字段依次为 `integrated_multimodal_description`、`overall_soundscape`、`non_diegetic_music`；全参考字段依次为 `subject_definitions`、`summary`、`retention_analysis`、`detailed_description` 以及上述两个声音字段。官方模板采用英文描述及空声音项的 `N/A` 表达。本 skill 默认按用户偏好交付下述中文创作正文，与严格重写模板区分，不宣称二者格式完全相同。

## 默认中文创作交付

默认将画面、动作、光线、运镜、表演和声音写成中文，用户明确指定其他正文语言时按主文件处理。每段代码块先简短保留本段总时长、已确定比例及必要的视觉或声音约束，再写必要的关键帧对齐句；镜头正文从 `[Shot 1]` 开始，不加 `integrated_multimodal_description:` 外壳。后续写 `[Shot 2] 在 00:04.500，……`。说话人使用稳定 `(S1)`，台词用 `<d>` 与 `</d>` 包裹，中文标记保留 `[Chinese]`；对白、歌词和可见文字保持原语言与原文。

先完成镜头设计，再套表达格式；标签不能代替构图、相对运动、动作前置条件与声音因果。需要完整纯文生成稿时读 [原创完整案例](../examples/classroom-drawing.md)，它展示同一内容的H3与Seedance适配，不代表所有任务的固定结构。

镜头正文之后，确有环境、动作或非语言人声设计时写 `overall_soundscape:`，值为中文；确有背景配乐时写 `non_diegetic_music:`，值为中文。没有的层直接省略，不输出 `N/A` 或空项。用户明确要求无配乐时可在总体声音约束中写“仅保留对白、环境音与动作声，无配乐”；完全静音则省略声音字段并明确“全片静音”，正文也不得保留对白或声音。省略字段只决定文本呈现，不承诺平台会自动禁用音乐。

用户明确要求官方完整重写格式、API 请求体或具体工具要求固定结构时，先查对应来源与入口；把中文创作正文和提交格式分开处理，不擅自把创作字段当 API 参数，也不在默认正文里恢复空占位。

## 模式操作

基础关键帧任务使用前从基础来源核对准确对齐句，放在镜头叙述前，替换镜头编号与秒数，不凭记忆拼装。来源无法取得时仍可完成中文创作草稿，但标明关键帧对齐表达待核实，不能声称严格适配或已锁帧；素材也未提供时另标待绑定。结束锚点必须与本次生成片段的时长一致，分段任务不能使用整片总时长。T2VA 不添加图片对齐句。

分段任务每段独立给出完整创作正文，并从 `[Shot 1]` 和本段0秒开始组织。正式尾帧对齐本段结束时间；提前到达目标状态及后续保持写在正文，不能把提前到达时间当成片尾。是否成功保持构图需成片验证。

Ref2VA 中，`<Subject N>` 是可复用内容，`<Picture N>` 是图片来源或帧锚点，`<Video N>` 是视频来源，`<Audio N>` 是实际使用的音频。主体编号和说话人编号各自稳定，不强求两者数字相同。

涉及全参考标签时查阅官方全参考来源的来源编号规则；需要严格全参考重写时再加载 `summary` 的任务前缀与 `retention_analysis` 关系枚举，不把内部分析字段强制展示给只要创作提示词的用户。无法获取来源时明确尚未验证格式，不能声称严格合规。

## 本 skill 的实现约定

- 保护用户原始台词标点；若某指南的标点规整建议与逐字保留要求冲突，以用户要求优先并说明必要差异。
- 不因源视频自带声音就创建音频引用，先确认该音轨实际参与任务。
- 仅音色参考不复制源音频的台词；原音频复用不自动改写语言。
- 区分在场人物画外发言与叙述者旁白，保持身份及声音连续，不让未发言的可见人物配口型。复杂旁白格式仍按官方来源核对，不发明新标签。
- 图片、音频标签需绑定真实输入；这些字段是提示词结构，不自动成为 API JSON 键。
- 本地缓存只保存关键决策；特殊旁白、跨镜对白、歌唱及复杂参考任务按需查官方来源。
