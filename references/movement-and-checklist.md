# 运镜决策与交稿前自查

每镜写运镜前使用。本文件只做两件事：帮每镜选一个有动机的运镜，交稿前按清单自查一遍。运镜的具体区别——推拉与变焦、拉焦、横摇与横移、手持与稳定长镜头——见 [经典镜头与运镜](camera-language.md)，这里不重复，只引用。

## 每镜只一个运镜，先问信息

运镜不是装饰。每镜先定本镜新增的信息，再选运镜。没有新信息，就用固定观察。

| 本镜新增的信息 | 可选运镜 | 起幅—触发—落幅 |
| --- | --- | --- |
| 发现一处细节 | 缓慢前推 | 中近景起幅—人物看向细节时启动—特写落幅，细节清晰后停住 |
| 从局部回到关系 | 缓慢后拉 | 特写起幅—动作完成时启动—中景或全景落幅，关系完整后停住 |
| 转向另一处信息 | 横摇或俯仰 | 机位不动—听到声音或视线转移时启动—新目标落幅，目标清晰后停住 |
| 陪伴一次行动 | 横移或跟拍 | 侧面起幅—人物开始走时启动—跟随到停步处，人物停下时相机收稳 |
| 同一构图中换关注 | 拉焦 | 机位焦段不变—声音或视线转移时启动—清晰平面从近处移到远处，构图尺度大体不变 |
| 看见物体的另一面 | 短弧环绕 | 正面起幅—需要看侧面时启动—半弧落幅，只看见另一侧就停，不用绕一圈 |

每镜只一个主要运镜。组合运动（又推又摇又拉焦）需要具体目的，不能把每个片段写成技法展示。速度要慢，慢到观众能跟上信息变化；快只在甩镜追突发动作时用，甩完要留出看清落点的时间。

易误写：每句对白都推近、每段末尾都后拉；边靠近边要求主体越来越小；“横摇穿过整条街”却没有说明实际位移。
可用写法：写清起幅看什么、由什么触发、相机如何变化、落幅看什么。到信息被看清时可停，不必全程移动。

## 运镜的速度与幅度

- 推拉：缓慢、平稳，到新关注对象明确后停止。
- 横摇俯仰：平缓，落幅留出观察时间。
- 横移跟拍：与主体同速，主体停下时相机收稳。
- 拉焦：只转移清晰平面，不改变构图尺度，不承诺前后同时最清晰。
- 滑动变焦：只有确需突出空间感突然变化时才用；机位与变焦反向配合，主体尺度大致稳定，背景需有纵深参照。普通推近不要升级成滑动变焦。

帧级剪辑、变焦和复杂复合运镜属于创作意图，执行前仍核对入口能力。入口无法稳定执行时，保留人物反应，改用普通推拉、固定观察或分镜。

## 交稿前自查清单

交付前逐项打勾。有一项不成立，先改提示词，不称最终可提交。

### 内容与结构

- [ ] 关键事件、对白、名物与关系覆盖正确；原文要求与创作假设区分，没有无意增删或重复。
- [ ] 原创短片：核心物件一句话能说清吗？开场是问句吗？三拍只写动作吗？两种解读真对立吗？金句只有一句、只讲物件吗？结尾停在物件上吗？（见 [以物件为先](object-and-reversal.md)。）
- [ ] 没有强行添加冲突、三幕或反转；没有角色 narrate 心情；没有第三个解释者；没有多余人物和场景。

### 时间

- [ ] 单段预算、切点、结束状态与标题相符；总长与各段合计一致；没有超载或空耗。
- [ ] 每段局部时间从 0 开始；切镜不增加可用时长；对白没有被加速或删减来强塞预算。

### 可见性与动作

- [ ] 信息在当前景别可读；关键细节有光照着；背景符合机位。
- [ ] 相机与主体运动一致；关键接触可见；手、承重和路线无冲突；关键动作只发生一次，不重复起手。
- [ ] 运镜有动机：每镜只一个主要运镜，起幅、触发、落幅、速度都写清了；没有为展示术语塞满技法。

### 光影与色彩

- [ ] 时间、主光源、方向、色温对照写清了；同一场景共用调色板；光源在各镜里连续。（见 [光影与色彩](lighting-and-color.md)。）
- [ ] 灯的位置和受光方向对得上；暗处没有要求所有细节都清晰。

### 连续性

- [ ] 片段、镜头之间身份、状态、持物、光源及声音能接续；揭示不等于变身，换装不等于换人。
- [ ] 每段重复必要的人物、场景与约束，只复制单段代码块仍能独立使用，不依赖“同上”。

### 镜头语言

- [ ] 视点与观众信息一致；推拉、变焦、拉焦及切镜没有混用；声桥和匹配剪辑未制造重复动作或错误时空关系。
- [ ] 比例已确定：16:9 还是 9:16，为什么选这个比例写清了；首帧比例与正文比例一致。

### 声画与格式

- [ ] 台词身份、音效时点和音乐层级清楚；对白只在该出现的镜头里出现，没有跨镜重复。
- [ ] 没有配乐就省略配乐字段；无字幕需求就不添加字幕；无空字段、未绑定引用、源模型语法及无关质量尾巴。
- [ ] 默认中文或用户指定语言；对白、歌词、可见文字保留原文、标点和语言。

### 整片与复制

- [ ] 各段推进整片表达；只复制单段代码块仍有时长、已确定比例、必要人物场景与约束。
- [ ] 负向约束写清了：无旁白、无解释字幕、无新增人物、无换场景、无煽情音乐（按实际需要取舍）。

## 用《7:42》走一遍清单

以下为本 skill 新编的原创练习自查示范，不是任何创作者的原作复刻。

- 第一版分镜只写“固定机位、特写、自然光”，自查时在“运镜有动机”和“光影写清”两项上失败：每镜都没有运镜，光源、时间、色温都没写。
- 改后版每镜只一个运镜（推、摇加跟、横移加拉焦、推、拉），光定为傍晚暖黄台灯对蓝灰暮色，关键一镜把手表和挂钟放进同一横屏画面，拉焦从前景手表移到背景挂钟。金句只有一句，只讲表，对白只在第四镜出现，结尾停在手表上。
- 失败的教训：固定观察本身没错，错的是没有先问“本镜新增什么信息”。没有新信息，固定观察才成立；有新信息，就得选一个运镜去接它。
